# WMC Launcher

WMC is an open-source, lightweight, and independent Minecraft Java Edition launcher developed by an individual developer. 

## Project Overview
This launcher is designed for personal and community use. It is currently in the development phase. The primary goal is to provide a clean, modern interface while maintaining high performance.

## EULA Compliance & Security
We strictly adhere to the Minecraft End User License Agreement (EULA) and Usage Guidelines. 
- WMC does **not** bypass any authentication, ownership checks, or license verifications.
- All players must authenticate via Microsoft OAuth 2.0 (Device Code Flow) to verify their game ownership before launching the game.
- We do not distribute any proprietary Minecraft assets, libraries, or intellectual property.

## Features (In Development)
- Microsoft Account login (Official OAuth)
- Offline mode support
- Automatic Java environment detection
- Version management and isolation
- Mod / Resource Pack support
